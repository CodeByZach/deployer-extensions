# Security policy

## Supported versions

Security fixes are released for the latest version of deployer-extensions. See the
[tags](https://github.com/CodeByZach/deployer-extensions/tags) for the current version.

## Reporting a vulnerability

Please don't report security problems in public issues. Report them privately
instead: [report a vulnerability](https://github.com/CodeByZach/deployer-extensions/security/advisories/new).

Include the deployer-extensions version, a proof of concept, and what an attacker could do.
You'll get a reply in the private report. Once a fix is released, a security
advisory is published that credits you, unless you'd rather not be named.
